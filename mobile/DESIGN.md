# Media Ops — Paper & Cobalt

Approved direction: Paper & Cobalt, 24 October 2026. The reference is `../docs/ui-concepts/01-paper-cobalt.png`. This document governs the Expo client; the root `src/` cue-sheet prototype is legacy.

Mode: Operate. Staff scan incoming media requests, prepare equipment and review email changes. Keep the app calm, ordinary and readable. Home rows describe requests across events; equipment controls belong inside details.

Use paper #F8F8F5, ink #171C2B, cobalt #345CD7, fine gray separators and soft blue icon tiles. Reserve amber for attention, red for overdue or errors, green for completed/tested work. Native system typography, 36-point screen titles, 32-point detail titles, 16-point body, 12–14-point metadata. Main gutters are 20 points; constrain wide screens to 720 points. Keep 44-point interactive targets and wrapping text. Avoid heavy shadows and ornamental dashboards.

Requests: brand/avatar, title/add action, honest mailbox or demo status, search, Active/Needs review/Completed tabs, grouped separated rows. Each row has an event icon, title/status, organizer, requirements summary, venue/time and deadline. Bottom navigation is Requests, Agenda, Settings.

Details: native back navigation, editable title, organizer, venue/date, blue deadline band, department requirements, assignments, Pending/Prepared/Tested segmented controls, source email and activity. Prepared is cobalt; Tested is green. The primary confirm/complete/reopen action stays visible above the device safe area. Preserve proposal review, manual corrections, completion, dismissal and reopening.

Use the same hierarchy for dark appearance. Colors for filled buttons must use `onAccent`, so pale dark-theme accents retain readable dark labels. Forms, settings and sign-in inherit shared typography and controls. Use the cobalt M/request-sheet brand mark for the icon and native splash; no arbitrary splash delay.
